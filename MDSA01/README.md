# MDSA01H3 (now MDSA10H3): Media Foundations

校历：[MDSA01H3 (now MDSA10H3)](https://utsc.calendar.utoronto.ca/course/mdsa10h3)

## 这门课学什么

A survey of foundational critical approaches to media studies, which introduces students to transnational and intersectional perspectives on three core themes in Media Studies: arts, society, and institutions. MDSA01H3 is the former code; the current calendar lists this content as MDSA10H3 (exclusion: MDSA01H3).

媒体研究基础：用跨国与交叉视角看艺术、社会、制度三个主题。现课号为 MDSA10H3。
