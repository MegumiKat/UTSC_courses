#### a:
Lets define STORAGE-BOX as:
**Input:** \<U, b, k> where U is a finite set of elements, each u $\in$ U has a size s(u) $\in$ N, b, k $\in$ N
**Question:** Can the elements in U be placed into k boxes, each of which has size at most b?
**Proof that STORAGE-BOX is in NP:**
1. It is a yes/no problem
2. **certification:** A function f: U $\rightarrow$ {1, 2, ..., k} that assigns each element in U to one of the k boxes. It can be represented as number of k sunsets, $B_1, ..., B_k, where B_i \subset U$, i = 1, 2, ..., k
3.  Since there are ∣U∣ elements and each element is assigned to one of k boxes, the certificate can be represented by ∣U∣ integers, each taking a value between 1 and k. Therefore, the size of the certificate is O(∣U∣), which is polynomial in the size of the input.
4.  The verifier would be:
    V = "On input \<U, b, k, f>:
    1.  Initialize an array box_sizes of length k to zero.
    2.  For each element u $\in$ U:
        1.  Check that f(u) $\in$ {1,2, ...,k}. If it is not, reject.
        2. Let i = f(u).
        3. box_sizes[i] += s(u).
        4. If box_sizes[i] \> b, reject.
    3. Accept if all elements have been assigned and no box exceeds size b; otherwise, reject.
5.  This verifier ensures that the certificate is valid by checking that each element is assigned to a valid box and that no box exceeds its capacity. The verification process runs in O(∣U∣) time, which is polynomial in the size of the input, thus satisfying the requirement for polynomial-time verification.

STORAGE-BOX is in NP, QED.
