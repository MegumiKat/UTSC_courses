# CSCC63H3: Computability and Computational Complexity

校历：[CSCC63H3](https://utsc.calendar.utoronto.ca/course/cscc63h3)

## 这门课学什么

Introduction to the theory of computability: Turing machines, Church's thesis, computable and non-computable functions, recursive and recursively enumerable sets, reducibility. Introduction to complexity theory: models of computation, P, NP, polynomial time reducibility, NP-completeness, further topics in complexity theory. Although CSCC63H3 and CSCC73H3 may be taken in any order, it is recommended that CSCC73H3 be taken first.

可计算性与复杂度：图灵机、Church 论题、递归集、归约、P/NP 与 NP 完全。`resources/vassor/` 是另一套补充材料。
