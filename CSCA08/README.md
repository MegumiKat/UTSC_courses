# CSCA08H3: Introduction to Computer Science I

校历：[CSCA08H3](https://utsc.calendar.utoronto.ca/course/csca08h3)

## 这门课学什么

Programming in an object-oriented language such as Python. Program structure: elementary data types, statements, control flow, functions, classes, objects, methods. Lists; searching, sorting and complexity. This course is intended for students having a serious interest in higher level computer science courses, or planning to complete a computer science program. No prior programming experience is required.

Python 面向对象入门：类型、控制流、函数、类、列表、搜索排序与复杂度。
