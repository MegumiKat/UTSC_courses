# CITA01 Reading Notes

与 `lecture-note` 配套。这里整理的是 `course reading/` 里现有 PDF 的论点、关键引语、编辑导读中的批判，以及你标注过的要点。

原始 PDF 仍在 `../course reading/`。本文件夹方便检索和写答案，不是原文替代。

## 怎么用来提问

- 「根据 `reading-note` 和 `lecture-note`，用 Madanipour 答 exclusion 题」
- 「Childe 的 10 条标准是什么？编辑导读怎么批评他？」
- 「把 Mattern 和 Al-Raeei 对打，分析 Toronto 的 AI 交通灯」
- 「用 Nejad 写 Indigenous placemaking 的 250 词答案」

优先顺序：

1. `00-reading-index.md`：哪篇阅读对应哪一讲
2. `readings/` 里的单篇笔记
3. `../lecture-note/` 里的讲义、术语表、对比表、考试指南

写期末答案时：**讲座给框架，阅读给作者原句和批判，视频给案例。** 视频笔记在 `../video-note/`。
