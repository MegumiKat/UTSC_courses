# 高频对比

期末和讨论帖经常要求比较。每组给出可直接写进答案的对照。

## Chicago School vs LA School

| | Chicago School | LA School |
|---|---|---|
| 代表 | Burgess (1925) | Dear 等，1980s–90s |
| 原型城市 | Chicago | Los Angeles |
| 城市区域 | 连贯的区域系统 | 碎片化 |
| 组织核心 | CBD 组织整个都市区 | 不同区域主要由全球力量塑造 |
| 动力 | 个人选择、入侵—演替、径向扩张 | 全球结构力量、公司主导的连接 |
| 发展观 | 线性、目的论 | 非线性、混乱 |
| 理论倾向 | 城市生态学 | 马克思主义、全球化 |
| 局限 | 芝加哥/美国中心；自然化种族与犯罪；忽视政治、全球过程、gentrification | 忽视性别；把 LA 当普遍模型；全球城市化塞不进单一形态模型 |

答题句：Chicago School 把城市看成从 CBD 向外扩张的有机系统；LA School 把当代城市看成被全球经济撕碎的 dual city。Toronto 今天更接近后者：金融核心、郊区碎片、全球资本和极化同时存在，但 CBD 仍有组织作用，所以不能完全丢掉 Burgess。

## Childe vs Davis

| | Childe | Davis |
|---|---|---|
| 问题 | 城市如何起源 | 人口如何城市化 |
| 方法 | 考古学 + 唯物论 | 人口学、历史统计 |
| 关键机制 | 农业剩余、分工、阶级、文字、国家 | 工业化、乡城迁移、S-curve |
| 时间 | 新石器 / Urban Revolution | 19–20 世纪加速 |
| 批判点 | 标准偏近东城市（Ur） | 目的论、欧洲中心、忽视殖民/战争/宗教 |

## Global cities vs Ordinary cities

| | Global / world cities (Sassen) | Ordinary cities (Robinson) |
|---|---|---|
| 焦点 | 指挥控制节点、高端生产性服务业 | 所有城市都是多样、争夺、独特的 |
| 风险 | 把城市排成等级，底层城市变成模仿者，理论无关 | 提醒后殖民城市研究不要只研究纽约—伦敦—东京 |

## Informal settlements vs “slums”

- **UN-Habitat informal settlements**：无合法土地权利，和/或不符合规划建筑规范； precarious occupancy、基本服务不足、废料建材。
- **“Slum”**：常被用来把贫困空间病理化。讲义问：何时叫 informal settlements，何时叫 slums？
- **Informal urbanism**：强调居住者的经验与能动，而不是只把他们写成问题。

## Incremental urbanization: Global South vs North

- 南方常被写成贫困异常、贫民窟景观。
- 北美二战前城市也是 bit-by-bit、没有总图，和后殖民城市今天的生长方式相似。
- 不要把 incremental 自动等同于失败。

## Massey: time-space compression vs power geometry

- Compression：交通通讯让地方显得更近，社会关系被拉长。
- 但体验不均：有人控制流动，有人被迫流动（难民、无证劳工）。
- 某些群体的流动与控制会削弱其他人。

## Economic / political / socio-cultural exclusion (Madanipour)

| 领域 | 包容 | 排斥 |
|---|---|---|
| Economic | 就业、资源 | 长期失业、无法生产/消费 |
| Political | 决策中的利害相关、投票 | 无代表（妇女、移民） |
| Cultural | 共享符号：语言、宗教、国籍 | 被边缘出仪式与话语 |

最严重的排斥是三者同时发生。空间上通过土地/房地产市场和空间商品化实现隔离。

## Public space vs private space

- Private：产权、围墙、合法排他。
- Public：原则上对所有人开放，但越来越受私人利益、监控、防御性设计影响。
- 连接：encampment 清拆、defensive architecture、Islamophobic 空间管制。

## Florida Creative Class vs McLean critique

| Florida | McLean |
|---|---|
| 创意阶级推动增长；城市要提供 technology, talent, tolerance | 创意城市策略服务全球城市野心、游客和投资者 |
| 3Ts、Bohemian/Gay/Melting Pot Index | 大型艺术节 = 文化政策新自由主义化 |
| 创意改造旧街区 | 把种族化社区奇观化；掩盖排斥；艺术家变成“发现”穷社区的殖民叙事 |

连接 gentrification：艺术家/学生当先锋 → 房价上涨 → 经济驱逐 + 文化置换。Regent Park 是 Toronto 例证。

## Urban planning vs urban design

- **Planning**：塑造建成、自然、社会环境，为公共利益；长期愿景；政策、法规、基础设施、住房、交通。
- **Design**：大于单栋建筑的场地；街道、公园、开放空间与建筑的相互关系；尺度从场地到新城。

## Jacobs vs Moses / Le Corbusier

- Moses / Corbusier：高速路、高层、功能分区、综合规划。
- Jacobs：街道生命、混合用途、eyes on the street、反对用郊区逻辑稀释城市。

## New Urbanism vs Green Urbanism

- New Urbanism：完整社区、人的尺度、多样性、节约；neighbourhood / district / corridor。
- Green Urbanism：传统城市主义 + 可再生能源、绿色技术、智慧电网；建筑 / 社区 / 公用事业三尺度。
- 二者相交：紧凑、步行、混合用途既节能又支持公交。

## Right to the city vs 普通“人人更多权利”

Lefebvre：不是给所有人加权利（有人已经特权），而是限制一些人的权利以增加另一些人的权利，追求公平。城市生活权不取决于产权或公民身份。对原住民，还需叠加土地权、自决、可见性（Nejad et al.）。

## AI 规划 vs Mattern

- 支持者：AI 提供数据，帮助高效、可持续、宜居决策（交通灯、坑洞、311）。
- Mattern：城市不是计算机。要看见数据的制造者、所有者、用户和批评者。需要记忆、历史、现场经验、参与观察、感官参与等多样知识。AI 可能复制住房市场不平等和歧视性警务。
