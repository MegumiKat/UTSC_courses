# CITA01 Lecture Notes

课程：**Foundations of City Studies**（城市研究基础）  
学期：Summer 2026  
讲师：Olivia Bernard  
用途：按主题检索讲义内容，并据此组织作业 / 讨论帖 / 期末答案。

原始 PDF 在 `../lectures/`。本文件夹是可检索的结构化笔记，不是幻灯片原文。课程阅读笔记在 `../reading-notes/`，课程视频笔记在 `../video-notes/`。写答案时讲座给框架，阅读给作者原句，视频给案例。

## 怎么用来提问

之后问问题时，直接说明要检索哪一类内容，例如：

- 「根据 `lecture-note`，解释 right to the city，并连到 Toronto encampments」
- 「比较 Chicago School 和 LA School，再判断哪个更适合 Toronto」
- 「用 Madanipour 的三种 exclusion 分析这个案例」
- 「按期末 250 词结构，答这个 case study」

优先检索顺序：

1. `00-topic-index.md`：主题 → 讲次
2. `00-glossary.md`：术语定义、作者、相关概念
3. `00-comparisons.md`：常考对比题
4. `XX-*.md`：该讲的完整要点、案例、批判
5. `00-exam-guide.md`：答题结构和引用策略

## 文件夹做什么

| 文件 / 文件夹 | 作用 |
|---|---|
| `00-course-overview.md` | 课程目标、评分、时间线、考试信息 |
| `00-glossary.md` | 核心术语表，检索入口 |
| `00-topic-index.md` | 主题、作者、Toronto 案例对照表 |
| `00-comparisons.md` | 高频对比（理论 / 学派 / 概念） |
| `00-exam-guide.md` | 期末题型、范文拆解、引用清单 |
| `01-*.md` … `12-*.md` | Detailed notes by lecture |
