## Q3

**Describe a scenario where running this endpoint could be harmful**
- If the database contains private images, exposing all images through this endpoint may cause a privacy violation.
- 
**Propose a solution to address this issue**
- We need **authorization checks** to ensure that only users with the appropriate permissions can access these images

**Pseudocode**
```
GEt /api/images/
function (req, res){
 user = req.session.user
 public_images = db.images.find({public: true});
 try{
  if (user.role !== 'admin'){
   return res.status(200.json(public_images));
  }else {
   all_images = db.images.findAll(); 
   return res.status(200).json(all_images);
  }
 }catch(error){
  console.error('Error'); 
  return res.status(500).json({ error: 'Error' });
 }
}
```
This will check the role of the logged in user and if the role is not admin then only res.json will be exposed as annotations, only users with admin role will have access to all images.
